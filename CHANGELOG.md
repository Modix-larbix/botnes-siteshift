# Changelog

## 0.1.0.0 (2026-10-29)

The visual launcher starts a new local MuJoCo episode from the browser and shows the robot moving through three camera views. It includes the three existing situations, a stop button, playback of the new run's saved frames, and an analysis of that run's evaluator records.

The repository now opens with the visual demo's setup instructions and explains the motivation, intended audience and current scope. The recorded evidence website remains available separately. The frozen simulator files, recorded model choices and historical evidence are unchanged.
